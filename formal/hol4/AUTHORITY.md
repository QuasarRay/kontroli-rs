# Metatheory authority map

This development does not treat a prose restatement written by an agent as the
source of truth. It mechanizes published rules and records the mapping.

## Primary metatheory

- Cousineau & Dowek, *Embedding Pure Type Systems in the lambda-Pi-calculus
  modulo* — foundational λΠ-modulo embedding/conservativity results.
- Assaf et al., *The λΠ-calculus modulo theory* / Dedukti presentations —
  declarative syntax, typing and conversion rules used by Dedukti.
- Saillard, *Rewriting Modulo β in the λΠ-Calculus Modulo* — conditions under
  which subject reduction and uniqueness of types hold.
- Dowek, *Models and termination of proof reduction in the lambda-Pi-calculus
  modulo theory* — semantic soundness/model results where applicable.

## Concrete checker contract

- Deducteam/Dedukti-standard — normative syntax/checking contract.
- Michael Färber, *Safe, Fast, Concurrent Proof Checking for the lambda-Pi
  Calculus Modulo Rewriting* — Kontroli architecture and kernel design.
- This repository's README and kontroli/src/kernel source — exact supported
  subset and implementation behavior.

## Required separation

The formalization must distinguish:

1. syntax and capture-avoiding substitution;
2. beta reduction;
3. user rewrite reduction;
4. conversion generated by reduction;
5. well-formed contexts/signatures;
6. declarative typing;
7. metatheoretic assumptions on rewrite systems;
8. soundness/subject-reduction/uniqueness theorems;
9. refinement from Kontroli's executable algorithms to the declarative model.

A theorem about implementation refinement is not a substitute for proving the
metatheory assumptions it relies on.
