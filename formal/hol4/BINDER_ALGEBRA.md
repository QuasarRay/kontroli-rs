# Binder/substitution algebra

This checkpoint restores proof infrastructure that an earlier PR description
referenced but did not actually contain.

Machine-checked targets in `LambdaPiBinderAlgebraScript.sml`:

- composition of de Bruijn lifting at a common cutoff;
- cancellation of one-step lifting by substitution;
- local-context lookup facts matching `LCtx::get_type`;
- explicit substitution-closure contracts for user rewriting and full
  beta+rewrite reduction;
- preservation of declarative EQC conversion by substitution when full
  reduction is substitution-closed.

The closure premise is deliberate.  Generalized typing substitution is false
for an arbitrary relation `R`; the final Kontroli refinement must prove that
the relation generated by admitted rewrite rules satisfies the contract.
